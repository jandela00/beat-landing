# b;eat Landing Page

로봇카페 **b;eat**의 영업용 랜딩 페이지입니다. 브랜드 소개부터 기술 경쟁력, 도입 상권, 수익 구조, 투자 유형, 개설 절차, FAQ, 상담 신청까지 한 페이지에 담았습니다. 모든 섹션은 PC와 모바일 화면을 모두 지원하고, 스크롤에 맞춰 순서대로 나타납니다.

## 데모

- Live: https://jandela00.github.io/beat-landing/

## 주요 기능

- **네비게이션**: 스크롤하면 헤더 배경이 어두워지고, 메뉴를 누르면 해당 섹션으로 부드럽게 이동합니다. 상단의 '상담신청' 버튼은 S16 상담신청 폼으로 이동합니다. 모바일(900px 이하)에서는 햄버거 메뉴로 바뀝니다.
- **스크롤 등장 효과**: 섹션 제목은 단어 단위로, 설명 문구와 본문은 순서대로 아래에서 올라오며 나타납니다.
- **FAQ 아코디언**: 처음에는 모두 닫혀 있고, 질문을 누르면 답변이 펼쳐지면서 질문 글자가 파란색으로 바뀝니다.
- **상담 신청 폼**
  - 국내(Domestic): 사업자 구분, 성함, 기업명, 연락처, 거주지, 문의 내용, 알게 된 경로(복수 선택), 개인정보 수집·이용 동의
  - 국외(Overseas): Name, Company name, Phone, Email address, Message, 영문 개인정보 동의
  - 필수 항목을 빠뜨리면 해당 칸에 빨간 테두리와 안내 문구가 표시됩니다.

> **참고**: 상담 신청 폼은 아직 실제 접수처(메일, 구글폼, CRM 등)와 연결되지 않았습니다. 입력값 검사만 하고 완료 문구를 보여줍니다. 접수처가 정해지면 `index.html`의 `TODO` 주석 위치에서 전송 코드를 연결하면 됩니다.

## 기술 스택

- **HTML5 / CSS3 / Vanilla JavaScript**: 프레임워크나 번들러 없이 `index.html` 파일 하나에 마크업, 스타일, 스크립트가 모두 들어 있습니다.
- 외부 라이브러리 의존성이 없습니다. 웹폰트(Pretendard)만 CDN에서 불러옵니다.
- 반응형 기준: PC(기본), 태블릿·소형 노트북(901–1300px), 모바일(900px 이하)

```
├── .claude/
│   └── launch.json     # 로컬 미리보기 서버 설정 (npx serve, 5173 포트)

└── README.md
```

## 로컬 실행 방법

설치할 것은 없습니다. 저장소를 받은 뒤 정적 파일 서버로 열면 됩니다.

```bash
git clone https://github.com/jandela00/beat-landing.git
cd beat-landing
npx serve -l 5173 .
```

브라우저에서 `http://localhost:5173`으로 접속합니다.

> `index.html`을 더블클릭해서 바로 열어도 대부분 정상으로 보이지만, 일부 브라우저는 `file://` 경로에서 영상 같은 리소스를 막을 수 있어 로컬 서버 사용을 권장합니다.
